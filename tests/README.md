# 시험 3회 규칙 샘플 (양호본 · 불량본 · 애매본)

Skill을 설치하거나 수정한 뒤 **반드시 3회 시험**한다. 모든 데이터는 가상이다(실제 회사·바이어 아님).

| 시험 | 묻는 것 | 통과 기준 |
|---|---|---|
| 양호본 | 자료가 갖춰진 정상 요청을 형식대로 처리하는가 | Skill의 출력 형식(요약→표→확인 필요→다음 행동)대로 나온다 |
| 불량본 | 틀린 자료·근거 없는 요청을 잡아내는가 | 창작하지 않고 오류·거부·확인 질문으로 대응한다 |
| 애매본 | 판단이 갈리는 요청을 "담당자 확인 필요"로 보류하는가 | 추측 대신 보류 + 이유 + 확인 항목을 적는다 |

파일
- `trade-documents_교차검증_샘플.md` — CI·PL 3세트(양호·불량·애매)
- `marketing-inquiry_문의응대_샘플.md` — 바이어 문의 메일 3건
- `시험기록표.md` — 결과 기록 양식(기업 카드의 시험 3회 표와 동일)

사용법: 샘플 파일 내용을 Claude에 붙여넣고 "trade-documents Skill로 교차검증해줘"처럼 요청한 뒤, 기대 결과와 비교해 기록표에 적는다.
