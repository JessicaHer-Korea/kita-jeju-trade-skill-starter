# 원산지 증빙 점검 가이드

## FTA와 C/O 발급 방식 (주요 대상국)
| 수입국 | 적용 가능 협정 | C/O 발급 방식 | 비고 |
|---|---|---|---|
| 태국 | 한-아세안 FTA | 기관발급 (Form AK) — 세관·상공회의소 | RCEP도 검토 |
| 베트남 | 한-베트남 FTA / 한-아세안 FTA | 기관발급 (Form VK / Form AK) | 협정별 세율·기준 비교 후 선택 |
| 일본 | RCEP | 기관발급 또는 인증수출자 자율발급 | 한-일 양자 FTA 없음 |
| 미국 | 한-미 FTA | 자율발급 (수출자·생산자·수입자) | 정해진 서식 없음, 필수 기재사항 |
| 중국 | 한-중 FTA / RCEP | 기관발급 | — |
| EU | 한-EU FTA | 자율발급 (6,000유로 초과 시 인증수출자 필요) | 원산지신고서 문안 |
| 아세안 기타 | 한-아세안 FTA / RCEP | 기관발급 | — |

※ 협정별 세율·기준은 FTA 통합플랫폼(fta.go.kr)에서 HS별로 확인.

## 원산지 판정기준 후보
- **완전생산기준(WO)**: 제주에서 양식·채취·생산된 원료 100% (광어, 원유 등에 해당 가능성)
- **세번변경기준(CTC)**: 수입 원재료의 HS와 완제품 HS가 달라지는 정도(CC/CTH/CTSH)
- **부가가치기준(RVC)**: 역내 부가가치 비율(협정별 기준 %)
- **특정공정기준**: 정해진 공정을 역내에서 수행
- 초콜릿·커피·화장품처럼 수입 원료(카카오·생두·향료) 비중이 큰 품목은 CTC/RVC 충족 여부를 반드시 계산해야 한다.

## 증빙서류 체크리스트
| 서류 | 보유 | 비고 |
|---|---|---|
| 원산지소명서 | ☐ | 판정기준·계산 근거 |
| BOM(원재료명세서) | ☐ | 원재료별 HS·원산지·단가 |
| 원재료 원산지(포괄)확인서 | ☐ | 국내 공급업체 발급 |
| 제조공정도 | ☐ | 특정공정 기준 대비 |
| 구매 세금계산서·거래명세서 | ☐ | 원재료 조달 증빙 |
| 수출신고필증 | ☐ | 기관발급 신청 시 |
| 인증수출자 인증서(해당 시) | ☐ | 한-EU 6,000유로 초과 등 |
| 비특혜 원산지증명서(상공회의소) | ☐ | FTA 무관·바이어 요구 시 |

## 주의
- 원산지 증빙서류는 협정별 보관 의무(통상 5년)가 있다.
- 사후검증 요청이 오면 위 서류로 소명해야 하므로 발급 시점에 세트로 보관한다.
- "제주산"은 마케팅 표기이고, 원산지증명서의 원산지는 "Republic of Korea"다.
