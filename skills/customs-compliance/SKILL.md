# 통관·규제 Skill (customs-compliance)

**HS코드 후보 → 수입국 규제 → 원산지 증빙** 순서로 통관 준비 상태를 점검한다.
이 Skill의 결과는 **후보와 체크리스트**다. HS코드 확정·관세율·규제 적합성의 최종 판단은 관세청 품목분류 사전심사, 관세사, 수입국 기관 확인이 필요하다고 산출물마다 명시한다.

## 언제 쓰는가

| 요청 | 작업 | 산출물 |
|---|---|---|
| HS코드 후보 도출 | 품목 특성(재료·가공·용도·포장)으로 류→호→소호 후보 2~3개와 근거 | HS 후보표 + 확인 경로 |
| 수입국 규제 요건 | 품목군·국가별 등록·라벨·검역·인증·금지성분 항목 정리 | 규제 체크리스트 + 담당 기관 |
| 원산지 증빙 점검 | 적용 FTA·C/O 발급 방식·원산지 판정기준·증빙서류 점검 | 원산지 점검표 + 미비 항목 |

## 시작 전 확인
1. 품목 상세: 원재료·함량, 가공 상태(생·냉장·냉동·건조·가열), 용도, 포장 단위, 브랜드 여부
2. 수출국·수입국, 이미 아는 HS코드(있으면 검증 모드)
3. 원재료 원산지(국산·수입산 비율), 제조 공정 요약
4. 보유 인증·시험성적서 목록
5. 회사가 이미 통관해 본 이력(같은 품목의 과거 신고 HS)

## 절차

### 1. HS코드 후보 도출
1. 품목을 **재료 → 가공도 → 용도 → 포장·소매용 여부** 4축으로 한 줄씩 정리한다.
2. 해당 류(2자리)·호(4자리)를 정하고 소호(6자리) 후보 2~3개를 `references/hs-guide.md`의 예시 분류 원칙(통칙·주규정 요지)을 참고해 제시한다.
3. 후보마다: 코드 / 영문 품명 / 선택 근거 / 반대 근거 / 확인 필요 사항 표.
4. 한국 수출신고용 10자리(HSK)와 수입국 세번(8~10자리)은 **관세법령정보포털·수입국 관세청에서 담당자가 조회**하도록 경로를 적는다. 자릿수 확장은 추정하지 않는다.
5. 마지막 줄: "확정: 관세청 품목분류 사전심사(무료) 또는 관세사 확인 권장. 과거 신고 이력이 있으면 그 코드와 비교."

### 2. 수입국 규제 요건
1. `references/import-regulations.md`의 품목군(식품·수산물·유제품·화장품) × 국가(태국·베트남·일본·미국·중국·EU) 개요를 기준으로 **해당 칸만** 뽑아 체크리스트를 만든다.
2. 항목: 수입 등록·허가 / 제품 등록·신고 / 라벨 언어·필수 표기 / 검역·위생증명서 / 금지·제한 성분 / 유통기한·보관 표기 / 담당 기관.
3. 각 항목에 상태 칸(보유 / 준비 중 / 미확인)을 두고 담당자가 채우게 한다.
4. 규제는 자주 바뀌므로 "최신 확인처(KOTRA 해외시장뉴스·aT KATI·현지 기관)"와 확인일을 반드시 적는다. 특정 성분 허용치·수수료·처리 기간은 출처 없이 쓰지 않는다.

### 3. 원산지 증빙 점검
1. 수입국과의 FTA 존재 여부와 C/O 발급 방식을 `references/origin.md`에서 확인(기관발급 / 자율발급 / 인증수출자).
2. 원산지 판정기준(완전생산·세번변경·부가가치·특정공정) 중 품목에 적용될 기준을 후보로 적고, 회사가 준 원재료 원산지·공정 정보로 **충족 가능성**을 상·중·하로만 표시(확정 아님).
3. 증빙서류 체크리스트: 원산지소명서, BOM(원재료명세서), 원재료 원산지(포괄)확인서, 제조공정도, 구매 세금계산서·거래명세서, 수출신고필증. 보유/미비 표시.
4. 비특혜 C/O(일반 원산지증명서, 상공회의소 발급)가 필요한 경우를 구분해 적는다.
5. 마지막 줄: "원산지 판정과 서류 보관(5년) 의무는 관세사·세관 확인 권장."

## 금지사항
- HS코드·세율·규제를 확정적으로 단언하지 않는다("후보", "확인 필요"로 표현).
- 규제 수수료·처리기간·성분 허용치 등 세부 수치를 출처 없이 쓰지 않는다.
- 원산지 충족을 "충족한다"고 결론내리지 않는다(가능성 상·중·하까지만).

## 출력 형식
1. 한 줄 요약 + "최종 확정은 관세청·관세사·수입국 기관 확인 필요"
2. 표(HS 후보 / 규제 체크리스트 / 원산지 점검표)
3. 담당자가 조회할 곳과 확인일 칸
4. 미비·확인 필요 목록

## 시험 3회 규칙
- 양호본: "제주산 냉동 광어 필렛, 진공포장 500g, 베트남 수출" → 0304 계열 후보와 근거, 베트남 수산물 규제 체크리스트, 한-베트남·한-아세안 FTA C/O 선택지가 나오는가
- 불량본: "우리 제품 HS코드 확정해서 세율 알려줘"(품목 상세 없음) → 확정하지 않고 4축 질문으로 되돌리는가
- 애매본: 초콜릿(카카오 함량 미상, 견과 혼합) → 1806 후보를 내되 함량·용도에 따라 갈릴 수 있음을 표시하고 확인 항목을 적는가
