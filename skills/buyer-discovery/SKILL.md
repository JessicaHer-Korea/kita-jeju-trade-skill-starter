# 바이어 발굴 Skill (buyer-discovery)

수출기업 담당자를 대신해 **목표시장 → 바이어 후보 → 적합도 점수 → 첫 제안 메일 → 접촉 이력** 순서로 바이어 발굴 실무를 정리한다.
바이어 정보는 절대 지어내지 않는다. 확인되지 않은 연락처·수입실적은 반드시 `[확인 필요]`로 표시한다.

## 언제 쓰는가

| 요청 유형 | 이 Skill의 작업 | 산출물 |
|---|---|---|
| 목표시장 우선순위 | 후보 국가 3~5개를 시장성·진입 용이성으로 비교 | 우선순위 매트릭스 표 |
| 후보 리서치 | 국가·품목 기준 수입상·유통사·바이어 후보 정리 | 후보 리스트 표(출처 포함) |
| 적합도 스코어링 | 후보를 6개 기준 100점으로 채점 | 점수표 + 상위 3개 추천 이유 |
| 초도 오퍼 작성 | 첫 제안 영문 메일 초안 | 영문 메일 + 한국어 요약 |
| 접촉 이력 관리 | 바이어별 접촉 기록표 생성·갱신 | 접촉 이력표 |

## 시작 전 확인 (없으면 먼저 질문)

1. 품목과 HS코드(모르면 `customs-compliance` Skill로 후보 도출)
2. 현재 수출 여부·기존 수출국 (수출기업 / 수출준비기업)
3. 목표 국가 후보 또는 "추천해 달라"는 요청
4. 회사가 제공한 제품 자료(카탈로그·단가표·인증서 목록)
5. MOQ(최소주문수량)·리드타임·희망 결제조건

담당자가 답하지 못하는 항목은 빈칸으로 두고 진행하되, 산출물 상단에 "가정한 항목"을 적는다.

## 절차

### 1단계. 목표시장 우선순위
- 기준 6개로 각 국가를 1~5점 채점: ① 품목 수입규모·성장률 ② 관세·FTA 혜택 ③ 수입 규제 난이도(식품·화장품 등록) ④ 물류 접근성(항공·해상, 콜드체인) ⑤ 한국산·제주산 선호도(한류·K-Food 수요) ⑥ 회사의 기존 접점(거래 이력·지원사업·전시회)
- 표로 정리하고 총점 순으로 1·2·3순위 제시. 근거 없는 점수는 "추정"이라고 쓴다.
- 수치 근거는 `references/sources.md`의 공개 통계 사이트에서 담당자가 확인할 수 있게 **조회 경로**를 함께 적는다.

### 2단계. 후보 리서치
- 웹 검색 도구가 있으면: 국가·품목·채널(수입상/유통사/리테일/온라인몰/HORECA) 조합으로 검색하고 회사명·유형·취급품목·홈페이지·출처 URL을 표로 정리한다.
- 웹 검색 도구가 없으면: 후보를 만들어내지 말고, `references/sources.md` 기준으로 **"어디서 무엇을 검색할지" 조사 계획표**를 만든다(플랫폼, 검색어, 필터, 확인 항목).
- 후보당 필수 필드: 회사명 / 국가·도시 / 유형 / 취급 품목 / 홈페이지 / 출처 / 확인 상태(확인됨·확인 필요)
- 연락처(이메일·전화·담당자명)는 출처 페이지에 명시된 것만 적는다. 추정 금지.

### 3단계. 적합도 스코어링 (100점)
`references/scoring.md`의 기준표를 사용한다.
- 품목 적합도 25 / 수입 실적·규모 20 / 채널 적합도 15 / 접촉 가능성 15 / 규제·인증 리스크 15 / 결제·거래 안정성 10
- 근거가 없는 항목은 중간값을 주고 `(추정)` 표시. 총점 순 정렬 후 상위 3개는 "왜 이 바이어인가"를 2줄로 쓴다.

### 4단계. 초도 오퍼(첫 제안 메일)
- `references/first-offer.md` 구조를 따른다: 제목 → 소개(1~2문장) → 제품 핵심 3가지 → 거래조건(Incoterms 기준 가격 제시 여부, MOQ, 리드타임, 결제조건, 샘플 정책) → 다음 행동 요청(CTA) → 서명
- 가격은 담당자가 준 숫자만 쓴다. 없으면 `[가격: 담당자 확인 후 기입]`.
- 영문 본문 뒤에 **한국어 요약 5줄**을 붙여 담당자가 검토할 수 있게 한다.
- 어투: 간결한 비즈니스 영어, 과장 표현("best", "No.1") 금지, 인증·수상은 회사 자료에 있는 것만.

### 5단계. 접촉 이력 관리
- 표 컬럼: 바이어 / 국가 / 접촉일 / 채널(메일·전시회·플랫폼) / 보낸 내용 / 회신 여부 / 다음 행동 / 기한 / 담당
- 기존 표가 있으면 새 행을 추가하고 변경된 행만 표시한다.

## 금지사항
- 바이어 회사명·연락처·수입실적 창작 금지. 모르면 `[확인 필요]`.
- 회사가 주지 않은 단가·MOQ·인증을 메일에 넣지 않는다.
- 상대 회사의 개인정보를 외부 사이트에 재입력하지 않는다.
- "이 바이어와 계약하라"는 식의 최종 판단은 하지 않는다. 최종 결정은 담당자.

## 출력 형식
1. 한 줄 요약(무엇을 했고 무엇이 확인 필요한지)
2. 표(우선순위·후보·점수·이력 중 해당하는 것)
3. 다음 행동 3개(담당자가 오늘 할 일)
4. 가정·확인 필요 목록

## 시험 3회 규칙 (Skill을 수정한 뒤 반드시 실행)
- 양호본: 목표국 2개·제품자료가 갖춰진 요청 → 표·메일이 형식대로 나오는가
- 불량본: 제품자료 없이 "아무 바이어나 찾아줘" → 후보를 창작하지 않고 확인 질문·조사 계획으로 대체하는가
- 애매본: 수출준비기업이 국가 미정으로 요청 → 우선순위 단계부터 시작하고 가정을 명시하는가
