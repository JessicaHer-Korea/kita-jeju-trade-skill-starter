# 바이어 적합도 스코어링 기준표 (100점)

| 기준 | 배점 | 5단계 채점 가이드 |
|---|---|---|
| 품목 적합도 | 25 | 같은 품목군 취급(25) / 인접 품목(18) / 식품·소비재 일반(12) / 취급품목 불명(8) / 무관(0) |
| 수입 실적·규모 | 20 | 한국산 수입 이력 확인(20) / 수입상 등록·규모 확인(15) / 규모 추정만 가능(10) / 정보 없음(5) |
| 채널 적합도 | 15 | 우리 제품 판매채널과 일치(15) / 부분 일치(10) / 불일치(3) |
| 접촉 가능성 | 15 | 담당자·이메일 공개(15) / 대표 메일·문의폼(10) / 플랫폼 경유만 가능(6) / 접점 없음(2) |
| 규제·인증 리스크 | 15 | 필요 인증 보유·등록 대행 가능(15) / 등록 필요하나 절차 명확(10) / 등록 난이도 높음(5) / 진입 불가(0) |
| 결제·거래 안정성 | 10 | 신용 정보·거래 레퍼런스 확인(10) / 회사 정보 공개(7) / 정보 없음(3) |

- 근거 없는 항목은 중간값 + `(추정)`.
- 70점 이상: 우선 접촉 / 50~69: 정보 보완 후 접촉 / 50 미만: 보류.
- 총점이 같으면 "접촉 가능성"이 높은 쪽을 앞에 둔다.
