# 바이어·시장 조사 공개 출처 (담당자 확인용 조회 경로)

아래는 담당자가 직접 접속해 확인할 수 있는 공개 사이트다. Skill은 이 목록을 근거로 "어디서 무엇을 볼지"를 안내하며, 사이트에 없는 수치를 만들어내지 않는다. 주소·메뉴는 변경될 수 있으니 접속 후 확인한다.

## 한국 기관
- **KOTRA 해외시장뉴스** (news.kotra.or.kr): 국가별 상품·산업 동향, 수입 규제, 바이어 인터뷰
- **buyKOREA** (buykorea.org, KOTRA): 해외 바이어 인콰이어리, 상품 등록
- **tradeKorea** (tradekorea.com, 한국무역협회): B2B 매칭, 바이어 DB, 거래알선
- **K-stat** (stat.kita.net, 한국무역협회): 국가별·품목별(HS) 수출입 통계
- **관세청 수출입무역통계** (tradedata.go.kr): HS코드별 국가별 수출입 실적
- **aT 농식품수출정보 KATI** (kati.net): 농식품 국가별 수출 정보·바이어 정보·규제
- **한국무역보험공사** (ksure.or.kr): 해외 바이어 신용조사 서비스(유료)

## 국제 통계
- **ITC Trade Map** (trademap.org): 국가별 수입액·수입국 순위(무료 가입)
- **UN Comtrade** (comtradeplus.un.org): HS 6단위 국제 교역 통계
- **WTO Tariff Data / Macmap** (macmap.org): 관세율·FTA 세율 조회

## 현지 조사
- 목표국 상공회의소·수입상협회 회원 명부
- 국제 식품·뷰티 전시회 참가사 디렉토리 (예: THAIFEX, Vietfood, FOODEX Japan, Cosmoprof, SIAL)
- 현지 대형 온라인몰(Lazada·Shopee·Amazon·Rakuten 등)에서 유사 한국 제품 판매자 역추적
- 현지 리테일 체인 홈페이지의 공급업체(Supplier) 안내 페이지
