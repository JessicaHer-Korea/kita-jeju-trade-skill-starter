# 시장·가격 Skill (market-pricing)

가격 판단에 필요한 **시세 → 환율 → 견적 → 포지셔닝**을 표로 정리한다.
시세·환율 숫자는 담당자가 준 값 또는 출처가 확인된 값만 쓴다. 출처 없는 숫자는 `[확인 필요]`, 계산은 반드시 식을 함께 보여준다.

## 언제 쓰는가

| 요청 | 작업 | 산출물 |
|---|---|---|
| 도매시세 동향 분석 | 국내·현지 시세 자료를 기간별·등급별 표로 정리, 변동 요인 요약 | 시세 동향표 + 3줄 해석 |
| 환율 반영 견적 | 원화 단가를 기준환율·버퍼로 외화 환산, 시나리오 비교 | 환율 견적표(±시나리오) |
| 가격 포지셔닝 | 현지 경쟁제품 가격대와 우리 제품 예상 소매가 비교 | 포지셔닝 표 + 권장 구간 |
| 소비자가 역산 | CIF → 관세·부가세 → 수입상·유통 마진 → 소매가 단계 계산 | 가격 구조표 |
| 해외출장·전시회 조사 | 매장·전시회에서 확인할 항목 체크리스트, 결과 기록표 | 조사 체크리스트 + 기록 양식 |

## 시작 전 확인
1. 품목·규격(용량·등급)과 비교 단위(kg, 개, 100g당)
2. 대상 국가·도시·채널(대형마트, 편의점, 온라인몰, HORECA)
3. 담당자가 가진 자료: 단가표, 과거 견적, 경쟁제품 사진·가격 캡처
4. 적용 환율 기준(기준일·출처)과 회사의 환율 버퍼 정책
5. 관세율·부가세율(모르면 `customs-compliance` Skill로 조회 경로 안내)

## 절차

### 1. 도매시세 동향
- 담당자가 준 시세 자료(또는 `references/sources.md`의 공개 시세 사이트에서 조회한 값)를 **날짜 / 등급·규격 / 단위 / 가격 / 출처** 표로 정리.
- 최근 4주·12주 변동을 %로 계산하고, 요인은 자료에 근거한 것만(계절·출하량·환율). 근거 없으면 "요인 미확인".
- 웹 검색 도구가 없으면 값을 만들지 말고 조회 경로와 입력 양식을 준다.

### 2. 환율 반영 견적
- 표 상단: 적용 환율 / 기준일 / 출처 / 버퍼 %.
- 외화 단가 = 원화 단가 ÷ 환율 × (1 + 버퍼). 식을 표 옆에 글로 적는다.
- 시나리오 열: 기준환율, −5%, +5%(또는 담당자 지정). 각 열의 외화 단가와 원화 환산 회수액을 함께.
- 결제 시점(선수금·잔금)이 다르면 시점별 환율 노출을 한 줄로 설명.
- 단가 로직 자체(원가→FOB→CIF)는 `trade-documents` Skill의 price-logic을 사용하고, 이 Skill은 환율·시나리오 부분을 맡는다.

### 3. 가격 포지셔닝
- 경쟁제품 표: 브랜드 / 원산지 / 규격 / 소매가(현지통화) / 단위당 가격 / 채널 / 출처(캡처·URL·조사일).
- 단위당 가격으로 정렬해 **프리미엄 / 중간 / 가성비** 3구간으로 나누고, 우리 제품 예상 소매가(4단계 역산 결과)를 같은 축에 놓는다.
- 권장 구간과 근거 2줄. "제주산·원료·인증"처럼 회사 자료에 있는 차별점만 근거로 쓴다.

### 4. 소비자가 역산
`references/price-structure.md` 단계: CIF → 관세 → 부가세(VAT) → 수입상 마진 → 유통 마진 → 소매가.
- 세율·마진율은 담당자 입력값 또는 출처 표시값만. 없으면 `[가정: xx%]`라고 명시하고 민감도(마진 ±10%p)를 보여준다.

### 5. 해외출장·전시회 현장 조사
`references/field-survey.md`의 체크리스트를 품목에 맞게 줄여 준다(매대 위치, 경쟁제품·가격, 포장 규격, 원산지 표시, 프로모션, 유통사명). 출장 후 사진·메모를 주면 조사 기록표로 정리한다.

## 금지사항
- 시세·환율·세율을 지어내지 않는다.
- 가격 결정(“이 가격으로 팔아라”)을 대신하지 않는다. 구간과 근거까지만.
- 경쟁사 가격은 조사일·출처를 반드시 붙인다(가격은 매일 바뀐다).

## 출력 형식
1. 한 줄 요약 + 적용 환율·기준일
2. 표(시세·견적·포지셔닝·가격구조 중 해당)
3. 계산식과 가정 목록
4. 다음 행동 3개

## 시험 3회 규칙
- 양호본: 원화 단가·환율·버퍼가 주어진 견적 → 3개 시나리오 표와 식이 맞는가
- 불량본: "지금 환율로 계산해줘"(환율 미제공, 검색 불가) → 환율을 만들지 않고 기준일·출처 입력을 요구하는가
- 애매본: 경쟁제품 가격이 용량이 제각각 → 단위당 가격으로 환산해 비교하고 환산식을 보여주는가
