# 해외출장·전시회 현장 조사 체크리스트

## 매장 조사 (마트·편의점·백화점 식품관·드럭스토어)
- [ ] 매장명·위치·채널 유형·조사일시
- [ ] 우리 품목군 매대 위치(입구/안쪽/냉장·냉동), 매대 폭(m), 페이싱 수
- [ ] 경쟁제품: 브랜드 / 원산지 / 규격 / 가격(현지통화) / 프로모션 / 사진
- [ ] 한국산·일본산·현지산 비율(눈대중 %)
- [ ] 포장 규격·언어 표시(현지어 라벨 스티커 여부), 원산지·인증 마크
- [ ] 냉장·냉동 진열 온도·보관 상태(콜드체인 품목)
- [ ] 유통사·수입사명(라벨 뒷면 Importer 표기 촬영)
- [ ] 시식·프로모션 인력 운영 여부

## 전시회 조사
- [ ] 우리 품목군 참가사 리스트(부스번호·국가·주력 제품)
- [ ] 바이어 명함·관심 제품·요청 조건(가격 기준·MOQ·샘플) 기록
- [ ] 트렌드 키워드(패키지·건강 소구·규격) 사진 10장 이상
- [ ] 현지 규제·인증 상담 부스 방문 여부
