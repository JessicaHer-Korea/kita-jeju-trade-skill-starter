# 제품 소개자료·상세페이지 구조

## 원페이저 (A4 1장, 영문)
| 섹션 | 내용 | 분량 |
|---|---|---|
| Headline | 제품 + 원산지 + 핵심 가치 (예: "Jeju Horse-Oil Soap – Handmade with island-sourced ingredients") | 1줄 |
| One-line definition | 무엇을 위한 제품인지 | 1문장 |
| Key strengths | 원료·제조·품질 강점 3개 (근거 있는 것만) | 3 bullets |
| From Jeju | 산지·생산 환경·회사 이야기 | 2~3문장 |
| Specifications | 규격·중량·입수·박스 규격·유통기한·보관 | 표 |
| Certifications & Safety | 보유 인증 목록, 시험성적서 유무 | 목록 |
| Trade terms | MOQ / Lead time / Price basis / Payment / Samples | 표 (담당자 확인값) |
| Contact | 담당자·이메일·홈페이지·플랫폼 링크 | 1줄 |

## 채널별 상세페이지 순서
| 채널 | 앞에 둘 것 | 뒤에 둘 것 |
|---|---|---|
| B2B 플랫폼 (tradeKorea·buyKOREA·Alibaba 계열) | 규격표 · MOQ · 인증 · 포장·선적 정보 | 스토리 · 사용법 |
| 온라인몰 (소비자) | 혜택 · 사용법·레시피 · 사진 | 규격 · 배송 |
| 자사 홈페이지·카탈로그 | 스토리 · 강점 | 규격 · 거래조건 |

## 상세페이지 섹션 템플릿
1. **Hero**: headline + sub-headline (사진 지시: 제품+제주 배경)
2. **Why [product]**: 3 benefits, 각 1문장 + 근거
3. **From Jeju, Korea**: 원료·생산 스토리
4. **Specifications**: 표(품명·규격·중량·성분·유통기한·보관)
5. **How to use / serve**: 사용법·레시피·페어링
6. **Certifications**: 로고·번호 (보유분만)
7. **Packaging & Shipping**: 입수·박스·팔레트·콜드체인
8. **FAQ**: 3~5개
9. **CTA**: 샘플·견적 요청 안내
- 마지막에 검색 키워드 5~8개, 메타 설명 1문장, 필요한 사진 목록.
