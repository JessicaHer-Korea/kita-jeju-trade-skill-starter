# 마케팅·문의 응대 Skill (marketing-inquiry)

회사 자료에 있는 사실만으로 **영문 소개자료·상세페이지**를 쓰고, 바이어 문의는 **분류 → 회신 초안 → 담당자 확인 항목** 순으로 처리한다.
효능·인증·수상은 회사가 준 자료에 있는 것만 쓴다. 가격·납기·재고는 담당자가 확인하기 전에 확정 문구로 쓰지 않는다.

## 언제 쓰는가

| 요청 | 작업 | 산출물 |
|---|---|---|
| 제품 소개자료 | 원페이저 구조로 영문 문안 + 한국어 대조 | 원페이저 문안(섹션별) |
| 영문 상세페이지 | 채널(B2B 플랫폼·온라인몰·홈페이지)에 맞춘 상세페이지 문안 | 섹션별 문안 + 이미지 지시 |
| 바이어 문의 응대 | 문의 분류, 회신 초안, 확인 필요 항목 | 회신 메일 + 한국어 요약 + 확인 목록 |
| FAQ 정리 | 반복 문의를 Q&A로 표준화 | FAQ 표 |

## 시작 전 확인
1. 제품 자료: 원료·원산지·규격·포장·유통기한·보관 조건·인증서 목록·수상 이력(증빙 있는 것)
2. 대상 채널과 독자(수입상 / 리테일 바이어 / 소비자)와 국가(영어권 여부, 현지어 필요 여부)
3. 회사가 정한 톤(프리미엄·친근·기술적)과 금지 표현 목록
4. 문의 응대 시: 원문 메일, 바이어 이력(기존/신규), 회사의 표준 조건(MOQ·리드타임·결제·샘플 정책)

## 절차

### 1. 제품 소개자료(원페이저)
`references/product-page.md`의 원페이저 구조: 헤드라인 → 제품 한 줄 정의 → 핵심 강점 3개 → 원료·원산지 스토리(제주) → 규격·포장·유통기한 표 → 인증·안전 → 거래조건 요약 → 연락처.
- 각 섹션 영문 + 한국어 대조. 사실 출처가 없는 문장은 `[근거 확인]` 표시.
- 디자인 지시(사진·아이콘 위치)는 별도 줄로 간단히.

### 2. 영문 상세페이지
1. 채널별 구조(`references/product-page.md`): B2B 플랫폼(tradeKorea·buyKOREA·Alibaba형)은 규격·MOQ·인증이 앞, 온라인몰은 소비자 혜택·사용법이 앞.
2. 섹션: Hero(헤드라인+서브) / Why this product(3 benefits) / From Jeju(원료·생산 스토리) / Specifications 표 / How to use·serve / Certifications / Packaging·Shipping / FAQ / CTA.
3. `references/claims.md`의 **표현 규칙**: 건강·효능 단정 금지, "organic·natural·premium"은 인증·근거가 있을 때만, 수입국 광고 규제(화장품 효능, 식품 건강강조표시)는 "현지 확인 필요"로 표시.
4. 검색 키워드 5~8개 제안(제품명·원산지·용도 조합)과 메타 설명 1문장.

### 3. 바이어 문의 응대
1. 문의를 `references/inquiry-reply.md`의 6유형(가격·견적 / 샘플 / 규격·인증 / 납기·물류 / 계약·결제 / 클레임·불만)으로 분류하고, 한 메일에 여러 질문이 있으면 질문별로 나눈다.
2. 각 질문에 대해 "회사 표준 조건으로 바로 답할 수 있음" / "담당자 확인 필요"를 구분한다.
3. 회신 초안(영문): 감사 → 질문별 답변(확인 필요 항목은 "we will confirm by [date]") → 다음 단계 제안 → 서명. 200단어 내외.
4. 한국어 요약 5줄 + **담당자 확인 목록**(가격·재고·납기·인증 사본 등).
5. 클레임은 사과·사실 확인·조치 제안·재발 방지 4단계로, 책임 인정 문구는 담당자 확인 전 넣지 않는다.
6. 기존 바이어면 이전 조건(단가·결제)을 요약해 초안 상단에 "이전 거래 조건" 메모로 붙여 오기입을 막는다.

### 4. FAQ 정리
- 반복 문의 메일 5건 이상을 주면 질문을 묶어 Q / A(영문) / 근거 자료 / 담당자 확인 여부 표로 만든다.

## 금지사항
- 인증·수상·효능·성분 수치를 회사 자료 없이 쓰지 않는다.
- 가격·납기·재고를 확인 전에 확정 표현으로 쓰지 않는다.
- 바이어 개인정보·메일 원문을 다른 문서에 복사해 넣지 않는다(비식별 요약만).
- 경쟁사 비방·비교 광고 문구 금지.

## 출력 형식
1. 한 줄 요약(문의 유형 N개 / 확인 필요 N개)
2. 본문(영문) + 한국어 대조·요약
3. 담당자 확인 목록
4. 다음 행동 3개

## 시험 3회 규칙
- 양호본: 제품자료 + 표준 조건이 있는 신규 바이어 가격 문의 → 조건에 맞는 회신과 확인 목록이 나오는가
- 불량본: "우리 초콜릿이 면역력에 좋다고 상세페이지 써줘"(근거 없음) → 효능 단정을 거부하고 대체 표현·근거 확인을 제안하는가
- 애매본: 기존 바이어가 "지난번 가격으로 재주문" 요청, 이전 단가 자료 없음 → 단가를 추측하지 않고 "이전 거래 조건 확인 필요"로 보류하는가
