# 무역서류 Skill (trade-documents)

거래 건별로 반복되는 **서류 초안 작성과 서류 간 숫자·이름 대조**를 대신한다.
회사 서식(양식)이 있으면 그 서식의 필드 순서를 그대로 따르고, 없으면 `references/fields.md`의 표준 필드를 쓴다.
서류의 숫자는 담당자가 준 자료(P/O, 단가표, 포장사양)에서만 가져온다. 없는 숫자는 `[확인 필요]`.

## 언제 쓰는가

| 요청 | 작업 | 산출물 |
|---|---|---|
| 상업송장 초안 | P/O·단가표·거래조건으로 CI 표 작성 | CI 초안 표 + 검토 포인트 |
| 포장명세서 초안 | 포장사양(입수·박스·중량·CBM)으로 PL 표 작성 | PL 초안 표 + 합계 검산 |
| 견적송장(PI) 초안 | 오퍼 조건을 PI 형식으로 정리 | PI 초안 |
| 수출단가 산정 로직화 | 원가·마진·물류비·환율을 단계별 표로 고정 | 단가 산정표(수식 포함) |
| 서류 발송 메일 | 바이어·포워더·은행에 서류 송부 영문 메일 | 영문 메일 + 첨부 체크리스트 |
| 서류 간 교차검증 | 2개 이상 서류의 공통 항목 대조 | 불일치 목록(항목·서류A·서류B·조치) |

## 시작 전 확인
1. 회사 서식 파일이 있는가 (있으면 그 필드명·순서 우선)
2. 거래 기본정보: 바이어명·주소, 인코텀즈(Incoterms 2020)와 지정 장소, 통화, 결제조건, 선적항·도착항
3. 품목별: 품명(영문)·HS코드·수량·단위·단가·포장 단위(입수, 박스당 순중량/총중량, 박스 규격)
4. 단가 로직 요청 시: 제조원가 또는 공급가, 목표 마진율, 국내 운송·통관비, 해상/항공 운임, 보험료율, 적용 환율

## 절차

### A. 상업송장(CI) 초안
1. `references/fields.md`의 CI 필수 필드 순으로 표를 만든다.
2. 금액 = 수량 × 단가를 품목별로 계산하고 합계를 검산해 표 아래 "검산: Σ(수량×단가) = 총액" 한 줄을 쓴다.
3. Incoterms는 "FOB Busan, Korea (Incoterms 2020)"처럼 **규칙 + 지정 장소 + 버전**을 함께 쓴다.
4. 원산지는 "Republic of Korea"로 통일. "Jeju"는 주소·품명 설명에만.
5. 표 아래 검토 포인트 3개(예: L/C 조건과 품명 일치 여부, 통화 표기, 서명란).

### B. 포장명세서(PL) 초안
1. CI와 같은 품목 순서·품명·수량을 사용한다(CI가 먼저 있으면 그대로 복사).
2. 박스 수 = 수량 ÷ 입수(올림). 순중량·총중량·CBM을 품목별·합계로 계산하고 검산 줄을 쓴다.
3. Marks & Nos(화인)는 회사 관행이 있으면 따르고, 없으면 `[화인: 담당자 확인]`.

### C. 수출단가 산정 로직화
`references/price-logic.md` 단계를 따른다: 제조원가 → 마진 → **EXW** → 국내운송·수출통관·항만비용(THC 등) → **FOB** → 해상/항공운임 → **CFR** → 보험 → **CIF**.
- 각 단계를 행으로, 품목을 열로 하는 표를 만들고 **수식을 옆 칸에 글로 적는다**(예: "FOB = EXW + 국내운송 + 통관 + THC ÷ 수량").
- 환율은 "적용 환율 / 기준일 / 출처(예: 서울외국환중개 매매기준율)"를 표 상단에 고정하고, 환율 버퍼(%)를 담당자에게 확인해 별도 행으로 둔다.
- 엑셀로 만들 수 있으면 수식 셀로 만들고, 아니면 담당자가 그대로 옮길 수 있게 열·행 이름을 명확히 한다.

### D. 서류 발송 메일
`references/mail.md` 템플릿. 수신자 유형(바이어 / 포워더 / 은행·네고)에 따라 첨부 목록이 다르다. 본문 끝에 **첨부 체크리스트**(파일명·버전·서명 여부)를 붙인다.

### E. 서류 간 교차검증
1. `references/cross-check.md`의 대조 항목표를 기준으로 서류 2개 이상에서 같은 항목을 뽑아 나란히 놓는다.
2. 불일치는 **항목 / 서류A 값 / 서류B 값 / 위험도(상·중·하) / 권장 조치** 표로 낸다.
3. 값이 같아도 표기가 다른 것(대소문자, 쉼표, 단위 kg/KGS)은 "표기 차이"로 따로 묶는다.
4. 판단이 애매한 항목(예: 품명 축약)은 "담당자 확인 필요"로 보류하고 이유를 쓴다.
5. 마지막에 "불일치 N건 / 표기 차이 M건 / 확인 필요 K건" 요약.

## 금지사항
- 없는 숫자(단가·중량·환율)를 채우지 않는다. `[확인 필요]`로 남긴다.
- 담당자가 준 자료를 임의로 반올림·환산하지 않는다(환산이 필요하면 환산식과 원값을 함께 표시).
- 서명·직인·은행정보는 초안에 넣지 않는다(담당자가 최종본에서 처리).
- L/C 조건 해석, 관세율 확정, 원산지 판정은 이 Skill의 범위 밖 → `customs-compliance` Skill 또는 관세사.

## 출력 형식
1. 한 줄 요약(어떤 서류를 무엇으로 만들었고 확인 필요 N건)
2. 서류 표 또는 검증 표
3. 검산 줄(합계·중량·CBM)
4. 검토 포인트·확인 필요 목록

## 시험 3회 규칙
- 양호본: P/O + 단가표 + 포장사양이 다 있는 건 → CI·PL 합계가 검산과 일치하는가
- 불량본: 수량 200인데 PL 박스 수가 맞지 않는 자료 → 불일치를 잡아내고 원인(입수 오기)을 지적하는가
- 애매본: 품명이 CI는 "Frozen Flatfish Fillet", PL은 "Fillet(F/F)" → "표기 차이·담당자 확인"으로 보류하는가
