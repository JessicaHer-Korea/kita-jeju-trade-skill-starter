# 서류 발송 영문 메일 템플릿

## 바이어에게 선적서류 송부
```
Subject: Shipping documents – Invoice No. [ ] / P/O [ ] – [Vessel, ETD]

Dear [Name],

Please find attached the shipping documents for your order P/O [ ]:
  1. Commercial Invoice No. [ ] (signed)
  2. Packing List
  3. Bill of Lading / Air Waybill copy (No. [ ])
  4. Certificate of Origin ([Form AK / VK / non-preferential]) – [attached / to follow]
  5. [Health certificate / Free sale certificate – if applicable]

Shipment details: [Vessel/Flight], ETD [date] from [port], ETA [date] at [port].
Payment: [balance 70% due before release of original documents / as per L/C].

Please let us know if any document needs amendment before [date].

Best regards,
[Name] | [Company]
```

## 포워더에게 서류 전달
```
Subject: S/R and documents – [Consignee] – [Booking No.]

Attached: Shipping Request, Commercial Invoice, Packing List, [export declaration no.].
Cargo: [ ] CTN / [ ] KGS G.W. / [ ] CBM, [dry / reefer -18°C].
Please confirm the booking, cut-off time, and send the B/L draft for our check before issuance.
```
